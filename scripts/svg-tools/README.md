# SVG-инструменты для физических/математических диаграмм

Переиспользуемые python-хелперы для рисования диаграмм к задачам курсов
ЕГЭ (физика/математика), в едином тёмном стиле приложения. Возникли при
массовом переносе задач с sdamgia.ru — там иллюстрация к задаче почти
всегда SVG, а наша задача — не скопировать его как есть (сторонний домен,
чужой стиль), а перерисовать **с той же геометрией**, но в своей палитре.

См. также подробную методологию декодирования оригинала в корневом
`CLAUDE.md` (раздел "Диаграммы к задачам").

## Файлы

- **`render_kinematic.py`** — линейные графики величина-от-времени (v(t),
  x(t), a(t), F(t)) с кусочно-линейной кривой по точкам `pts`. Используется
  для графиков скорости/координаты/ускорения (кинематика).
- **`render_energy_graph.py`** — параболические графики (кинетическая /
  потенциальная энергия от времени при вертикальном броске). Две функции:
  `render_parabola` (ветви вверх, ноль в вершине) и
  `render_inverted_parabola` (ветви вниз, максимум в вершине).
- **`render_physobj.py`** — набор примитивов для схем "брусок/пружина/
  верёвка/стена/сила": `block`, `spring`, `rope`, `arrow`, `hatch_line`
  (штриховка стены/земли), `circle_pt`, `text`, `dashed_line`, а также
  `vector_grid` — готовый рендер диаграммы сложения векторов сил на сетке
  (по образцу sdamgia: "1 клетка = 1 Н" и т.п.).
- **`render_spring_block.py`** — частный случай схемы "брусок на пружине у
  стены, сила F" (обе полярности — растяжение/сжатие).

## Единый цветовой стиль (дублируется в каждом файле как константы)

```
BG    = "#151F23"   фон канваса (совпадает с фоном страницы урока)
GRID  = "#3A464E"   сетка
AXIS  = "#9AA7B0"   оси, стены, земля
CURVE = "#f0a868"   сама кривая графика / вектор
TEXT  = "#F2F7FB"   подписи (Georgia, serif, часто italic — под формулы)
DOT   = "#0369a1"   обводка точек-маркеров на кривой
```

Шрифт подписей всегда `Georgia, serif` (иногда `font-style="italic"`,
похоже на курсив формул в самих задачах). Экспортированный `<svg>` кладётся
в `public/geometry/<имя>.svg` и подключается как `imageSrc` задачи вида
`/geometry/<имя>.svg`.

## Как обычно используется

Это не CLI-утилита с общим входом — под каждую новую диаграмму пишется
маленький скрипт-обёртка (см. пример в конце `render_spring_block.py`),
который импортирует нужный рендерер и вызывает его с параметрами,
подобранными под конкретную задачу (декодированными из оригинального SVG
sdamgia или взятыми из условия). Типичный цикл:

1. Скачать оригинал: `curl -s "https://phys-ege.sdamgia.ru/get_file?id=<ID>" -o orig.svg`
2. Разобрать геометрию (см. методологию в корневом `CLAUDE.md`)
3. Вызвать подходящий рендерер из этой папки с полученными числами
4. Открыть результат в Browser pane (см. `preview_start`/`navigate` в
   инструментах Claude) и визуально сверить с оригиналом **до** того как
   класть файл в `public/geometry/`
5. Сохранить готовый `.svg` в `public/geometry/`, использовать его путь в
   поле `imageSrc` seed-скрипта

Файлы `if __name__ == '__main__':` в некоторых из этих скриптов — лишь
пример вызова с путями во временную папку конкретной прошлой сессии;
не рассчитывайте, что они отработают "из коробки" — берите функции и
вызывайте их со своими параметрами и своим путём вывода.
